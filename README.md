# Speculative Relics — Interactive 3D Viewer

An interactive Unity-based viewer for exploring digitized historical objects in 3D.

This project presents reconstructed artifacts in a gallery-style environment, with a focus on close visual inspection, material detail, and simple object interaction.

**[View the interactive experience](https://meva08.github.io/speculative-relics-3Dviewer/)**

## Features

- Click-and-drag rotation for inspecting objects from multiple angles
- Gallery-style lighting designed to highlight surface texture and normal-map detail
- Interactive controls for opening or resetting specific artifacts
- WebGL build for browser-based viewing
- Optimized Blender-to-Unity workflow using baked albedo and normal maps

## Built With

- Blender
- Unity 6
- Universal Render Pipeline (URP)
- WebGL
- GitHub Pages

## Interaction

Use the mouse to click and drag the artifact to rotate it.

Some objects include additional interface controls, such as:

- **Open / Close** — reveals interior surfaces
- **Reset View** — returns the artifact to its original orientation

## About

This viewer was developed as part of a portfolio project exploring how historical objects can be presented as interactive digital artifacts rather than static documentation.
